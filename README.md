# Illustra — versão do site

Versão estática da Illustra com páginas inicial e sobre, pasta de imagens, scripts e estilos. O título da página inicial é `Illustra`.

## Estrutura

- `index.html` (ou o caminho indicado abaixo): página inicial.
- Arquivos HTML adicionais: páginas internas, quando presentes.
- Pastas de estilos, scripts e imagens: apresentação e recursos visuais.

## Como executar

Abra o projeto no VS Code e visualize o arquivo HTML indicado com Live Server ou diretamente no navegador.

```bash
git clone https://github.com/Pedro-Bonelli/pedro-site.git
cd pedro-site
```

Ponto de entrada: `index.html`. Não há etapa de instalação de pacotes na raiz.

## Observações

Há outro repositório `illustra` com estrutura semelhante; trate ambos como versões até comparar suas diferenças.
